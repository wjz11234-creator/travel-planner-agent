# P0 实现说明

目标：证明「调度」和「专家」是分开的 LangGraph 节点，而不是一个 Prompt 里两个角色扮演。

## 已实现

- Supervisor：规则 + LLM 判 `qa | plan | revise`，可抽出目的地写入 `profile`
- GuideAgent：关键词检索 `backend/knowledge/` 后作答；材料不足则明确说不知道
- PlanStub：P1 流水线未上线时的占位专家（前端显示为 Planner）
- SSE：`agent` → `intent` → `text` → `done`，气泡标注当前 Agent
- 鉴权：注册/登录 Cookie；游客不落库；已登录会话绑 user_id

## 图

```
START → supervisor → (qa) guide → END
                   → (plan|revise) plan_stub → END
```

## 验收用例

1. 京都四月穿什么 → `intent=qa`，Guide 引用京都攻略中的四月着装
2. 东京塔几点关门 → 知识库无精确时刻则拒绝编造
3. 帮我做东京 5 日 → `intent=plan`，Planner 占位，不输出按天行程
