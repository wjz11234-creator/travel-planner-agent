# 第 1 关：需求分析拆解

**来源：** 本轮对话 + `input/materials.md` 的 Figma。**第 3 关拉稿后已按设计稿交互修订**（原「未对照任务页」仍成立：无 Notion）。

**范围：前后端都出方案。** 要改鉴权、会话归属、SQLite、会话 API，以及 `docs/DESIGN.md` 与 `web/src/types/itinerary.ts`。

当前现状：无账号；会话写入 SQLite；`localStorage` 存 `travel-planner-session-id`；`GET /api/sessions` 列出全部会话。

---

## 本期要做

独立**登录 / 注册 / 忘记密码**全屏页（旅途知己卡片，水彩背景）。未登录默认登录页；可「跳过登录，直接体验」进工作台（游客）。已登录进工作台。工作台侧栏底栏设置里**退出登录**。登录用户会话长期保存在服务端；游客不长期保存。

## 本期约定（以 Figma 交互为准）

1. **产品名：** 旅途知己（实现时工作台/鉴权文案跟稿，不沿用侧栏「Travel Planner」作为主品牌）。
2. **账号：** 登录字段为「邮箱 / 手机号」+ 密码。注册另需「昵称」「确认密码」（至少 8 位）。标识符按字符串存（邮箱或手机号），本期不做短信网关。
3. **忘记密码：** 独立页：输入邮箱/手机号 →「发送验证码」→「返回登录」。本期**不接真实短信/邮箱**，点发送给出成功或占位提示即可走通交互。
4. **游客：** 登录页「跳过登录，直接体验」进入工作台。工作台顶部游客横幅：「你正在使用游客模式，数据不会长期保存。」+「立即注册」+ 可关闭。对话只在当前标签页；刷新/关页清空；侧栏无历史。
5. **登录用户：** 侧栏「历史行程」为本人会话；底栏显示昵称；设置图标弹出「退出登录」。
6. **游客中途点立即注册：** 进入注册页；不自动合并当前游客气泡。
7. **退出：** 清登录态，回到登录页。
8. **P0 问答：** Guide / Planner 占位 / Agent 徽章规则不变。Figma 工作台里的按天行程卡片是视觉示例，**本期 Planner 仍不产出按天卡片**。

## 可测验收

| 编号 | 场景 | 期望 |
|---|---|---|
| A1 | 未登录打开应用 | 先到登录页（旅途知己卡片），不是直接进工作台 |
| A2 | 点「跳过登录，直接体验」 | 进入工作台；有游客横幅；侧栏历史为空 |
| A3 | 游客问「京都四月穿什么」 | 仍走 Guide，气泡有 Agent 徽章 |
| A4 | 游客发消息后刷新 | 回到登录页或空游客工作台且消息不在；无该会话历史 |
| A5 | 注册：昵称 + 未占用标识 + 两次密码一致且 ≥8 | 成功并进入工作台已登录 |
| A6 | 注册：标识占用 / 密码过短 / 两次不一致 | 错误提示，仍在注册页 |
| A7 | 登录：正确标识+密码 | 进入工作台；可见本人历史（若有） |
| A8 | 登录：错误密码 | 错误提示，仍在登录页 |
| A9 | 登录页「注册账号」/ 注册页「去登录」/「忘记密码？」 | 在三页间切换 |
| A10 | 忘记密码页点发送验证码 | 有反馈（占位即可）；「返回登录」回到登录页 |
| A11 | 已登录发消息后刷新 | 仍登录；会话仍在 |
| A12 | 设置 → 退出登录 | 回到登录页；看不到该账号历史 |
| A13 | 游客横幅「立即注册」 | 打开注册页 |
| A14 | 「新建会话」 | 已登录：新开空会话。游客：清空消息，意图 `—` |
| A15 | 东京塔几点关门 / 东京 5 日 | 原 P0（Guide 可不知道；Planner 占位，无按天卡片） |

## 不做

- 订票；P0 按天行程卡片（即便稿里有 Day 卡片示例）
- OAuth / Google 登录（稿中登录卡无第三方按钮）
- 真实短信/邮件验证码网关、完整「填验证码改密」后页
- 游客云端同步、登录时自动合并游客聊天
- 会话重命名/删除弹窗（稿有规范，**非本期鉴权必做**；可后续）
- 发明未先写入 `DESIGN.md` / `itinerary.ts` 的 API 或 State 字段
